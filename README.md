Proyecto en Java que implementa algoritmos de búsqueda de forma recursiva sobre un vector de enteros aleatorios.

## Algoritmos incluidos
- **Búsqueda secuencial recursiva**: indica si un valor existe en el vector.
- **Búsqueda por índice**: devuelve la posición del valor o -1 si no está.
- **Búsqueda binaria recursiva**: requiere que el vector esté ordenado.

## Estructura
- `src/back/BusquedaRecursiva.java`: lógica de los algoritmos.
- `NewJFrame.java` / `NewJFrame.form`: interfaz gráfica (Swing).
- `nbproject/`: configuración de NetBeans.
